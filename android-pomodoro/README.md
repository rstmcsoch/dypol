# Pomodoro — DYPOL LABS

A dependency-free Android Pomodoro timer focused on a fast, offline experience.

Features:
- Focus / short break / long break modes
- Start, pause, restart, skip
- 5–120 minute focus duration selector
- Automatic next-session option
- Completion vibration
- Light/dark mode
- Resizable, draggable floating timer using the Android overlay permission
- Local-only state; no accounts, analytics, cloud sync, or internet permission

The floating timer is implemented as an adjustable overlay. Android's system PiP window size/placement is ultimately system-controlled, so the adjustable floating mode is the reliable way to provide the requested freely resizable focus widget.
